## 核心结论

1. 薅羊毛（签到、注册礼）是孙学的反面——补贴停了你归零。
2. 大头在渠道层：B.AI 邀请人拿永久 Coin，散户拿 30 天过期的积分；导航站/实测号/公益站站长是被补贴方。
3. 信息流：linux.do 公益推广标签、panxunying/ai-coding-welfare（RSS）、wynx1123/ai-welfare-hub（live.json）、r/LocalLLaMA、cheahjs/free-llm-api-resources。
